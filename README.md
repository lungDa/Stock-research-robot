# 股海燈塔：台股年度EPS補登與股利支出辨識更新

採用已確認的方式：歷史年度EPS由使用者依官方完整年度財報核對補登；現金股利支出補強FinMind現金流科目辨識。不把季度EPS直接相加，也不以配息公告×股數估算實付股利總額。

## 安裝

將包內app、jobs、streamlit_app.py與tests依原路徑覆蓋／新增到GitHub main，保留其他檔案。等Render和Streamlit部署完成。無需新增Secret、套件或資料表。

再到Actions → Refresh free annual data → Run workflow，更新現金流資料。舊版現金流快取會重新下載一次以補回原始科目，仍遵守來源冷卻及每次最多8次年度請求限制；失敗不會每次重跑都繞過冷卻。美股日線步驟和既有排程沿用不變。

## 補登步驟

Streamlit → 完成LINE個人登入 → 評分與通知設定 →「補登台股年度 EPS 與現金股利支出」。

1. 填台股代號，例如2330；上櫃要明寫.TWO。
2. 到公開資訊觀測站或公司投資人關係網站查該年度完整合併財報。
3. EPS填1月1日至12月31日的全年基本每股盈餘（TWD／股），不填第四季單季EPS、稀釋EPS、預估值或TTM。
4. 股利支出填現金流量表全年支付現金股利總額，選擇元／千元／百萬元。系統會統一換算為元，EPS不隨此單位放大。
5. 十個年度表格中，只填你要補的欄位；每個有填寫的年度都須附該年度官方年報或財報HTTPS來源網址。
6. 勾選已核對公司、完整年度、合併範圍與單位，再儲存。
7. 回個股查詢重新按分析，檢查個人年度數值與評分。

可只填EPS或只填股利支出。空白不刪除舊值，負EPS有效，股利支出填非負數；0代表明確填入零，不代表缺資料。每列至少填一項。

「查看我的補登資料」顯示已保存數值及欄位來源。該表股利支出已換算為元，重新填回時請選對單位，避免重複乘1000。

請勿把每股配息、董事會宣告金額、應付股利餘額、利息與股利的混合科目，當作全年支付現金股利總額。財報的幣別、單位與合併範圍須與其他年度現金流一致。

## 個人資料與來源

只寫入目前登入者的個人年度資料，不修改共用來源或別人的清單及設定。已填欄位優先於自動資料，其他欄位保留。整份驗證後才寫入，一列錯誤就整批不保存。

每個補登欄位保留來源網址、核對日期、原始單位與換算單位。來源網址只保存，不由伺服器下載。資料標示user_report_verified，意為使用者已核對，不代表系統已自動驗證原始報表。

既有CSV匯入仍會取代該檔完整個人年度資料；需要保留其他欄位時，請用新補登介面。

## 自動股利支出辨識

舊版只保留兩個完全相同的中文名稱，其他股利科目可能在快取階段就被丟掉。本版先保留含股利／股息的原始現金流科目，再以明確科目白名單判定。

- 使用12月31日全年累計，不加總四季累計值。
- 接受已辨識的支付／發放股利科目；相同金額重複只取一次。
- 金額互相衝突時留白，不把不同總額相加。
- 不用應付股利、宣告政策、非控制權益股利子項或「利息及股利」混合科目替代。
- 成功下載現金流後，紀錄會列cash_dividend_labels（最多20個原始科目名稱），方便核對；不輸出Token或Header。

來源沒有該科目或名稱仍未辨識時會繼續留白。請查看年度更新步驟的cash_dividend_labels，或由官方年報核對後補登，不宣稱所有公司都已自動補齊。

## 驗證

本機測試涵蓋使用者隔離、單位換算、負EPS、零股利、空白保留、整批驗證、API認證與大小限制、科目保留、衝突拒收及一次快取更新。Streamlit測試驗證表格能顯示、選擇千元、提交已填年度並出現成功訊息。

尚未在你的正式環境執行此次更新。完成補登不表示符合選股門檻，數值仍會逐條比較你的個人設定。
