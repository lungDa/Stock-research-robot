# 股海燈塔：近一年EPS、ROE及已到發放日現金配息率

## 此版本的範圍

採使用者選擇A：近一年口徑，適用台股及美股個股。增加獨立TTM資料表格並用可核對的近一年值更新簡式存股條件；原本多年平均EPS、ROE、年度殖利率及最近完整年度EPS等個人規則仍用年度資料，不默默改成TTM。

這不是所有股票都能自動補滿三項數值的保證。涵蓋範圍：

- 台股ROE：FinMind近四個完整季度稅後淨利合計，除以同期間期初、期末總權益平均。四季須齊全；ROE以百分比展示、簡式條件用小數比較。
- 美股ROE：SEC同幣別、同科目的12個月淨利／平均期初期末權益。必要時使用「上一完整年度＋本期累計−去年同期累計」，不相加重疊期間。缺任何端點或匹配期間就留白。
- EPS：優先使用SEC中與最新淨利TTM期間完全一致、已揭露的12個月稀釋EPS。不直接加總股數基準未核對的四筆EPS，也不把舊年度EPS冒充最新TTM。台股及缺漏美股可用新TTM EPS核對補登；仍需使用者查核近一年值及股數基準。
- 台股配息率：FinMind可取得的公告發放日紀錄，僅計入已到發放日、落在最近365天的現金配息，除以最新可用收盤價。按發放日而不是股利所屬年度，也不使用公告殖利率。
- 美股配息率：本版自動發放日來源僅接入AAPL的Apple官方Dividend History；其他美股尚未有已核對來源時留白，不宣稱已涵蓋全部美股。
- 排除未來發放日；來源紀錄須涵蓋365天窗口之前，且有已知拆股／配股跨過窗口時不使用未調整金額。不能證明涵蓋或價格過舊時留白，不把缺資料當0。

「已到發放日」依官方／供應商公告日期推定，不等於系統查核股東銀行實際入帳。來源修訂或未涵蓋的公司事件仍可能影響數字。

## 安裝

將包內app、jobs、tests、.github/workflows與streamlit_app.py依原路徑覆蓋／新增到GitHub main，保留其他檔案。這是前面台股補登、美股日線修正包的延伸，必須保留已安裝的專案。

等待Render與Streamlit部署後，Actions → Refresh free annual data → Run workflow：
1. 更新年度及SEC的季度期間資料。
2. 更新既有美股日線快取。
3. 新增Refresh verified issuer payment dates步驟，最多抓一個已核對公司股利頁（目前AAPL）。

不用新增金鑰，沿用FINMIND_TOKEN、SEC_USER_AGENT、DATABASE_URL與ANNUAL_SYMBOLS／成員追蹤清單。沒有追蹤AAPL或ANNUAL_SYMBOLS未含AAPL時，Apple步驟會略過，不代表失敗。

SEC所需期間資料及台股配息舊快取會在版本更新後重新下載一次，仍共用原有請求上限、時間上限及來源冷卻；失敗不無限重試。標的多時需輪替多批，資料不會立即全部出現。

## 驗證

重新分析2330及AAPL，在「近一年基本面（TTM／近365天）」檢查：數值、起日、迄日、股價日、來源與口徑。

- ROE缺少四季淨利或任一端點權益時留白。
- EPS只有完整年度、沒有最新TTM期間時仍留白。
- 未來股利不納入。近365天窗口以查詢日為終點，分母股價日另行列出。
- 股價需在7天內且不是失敗備援舊價；財報期末距今超過190天，不當作可用TTM。
- Yahoo Dividends原以除息日為索引，這版不再把它標示成已發放日口徑。美股日線快取仍優先FinMind，不增加網頁端Yahoo請求。
- 資料不完整時仍顯示缺漏原因，不會以高部分分數宣稱條件全部符合。

## 個人TTM EPS補登

LINE登入後 → 評分與通知設定 →「核對補登近一年 EPS（台股／美股）」：

1. 填代號、報表近一年起訖日、可核對TTM EPS及官方財報HTTPS網址。
2. EPS用報表幣別每股：台股TWD／股，美股USD／股，不自動換匯。
3. 須核對近四季股數基準一致，不把第四季單季值、年度值、估計值直接當TTM。
4. 勾選確認後保存，再重新分析。

個人補登只影響自己，保留來源與期間，不寫共用資料、不覆蓋原有年度EPS。標示為使用者核對，系統未自動驗證報表內容。負EPS可保存；未來、過舊或不滿近一年的期間會拒收。

## 流量與限制

年度工作維持最多8次HTTP請求、1MiB／份、每份6秒軟預算；既有美股日線最多2次請求。Apple來源新增最多1次請求、256KiB、6秒軟預算、每天一次，失敗保留舊快取，步驟硬限制1分鐘。整個工作仍有原本GitHub工作流程硬限制。

因此每輪最多8次年度＋2次美股日線＋1次官方配息頁，無網頁／LINE端新增外部財報請求。官方頁HTML結構改變、回應過大、網路失敗時會留白。來源來源資料快取最多容許8天；超出不作當前配息率。

本機測試涵蓋TTM期間配對、年度與YTD重疊排除、ROE起訖權益、未來股利排除、股價日期、拆股拒算、補登使用者隔離與API限制，並驗證Streamlit表格及補登介面可渲染。尚未在你的正式服務完成這版端到端驗證。
