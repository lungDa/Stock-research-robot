## 這版會有什麼不同

- 新增公開資訊觀測站「財務比較 E 點通」全年 EPS／ROE 來源，涵蓋上市及上櫃，不需要 FinMind token。只查第4季累計／全年，核對公司、期間、單位及來源欄位，不取第四季單季值。
- 新增嚴格 TTM EPS 獲利與股數核對計算：四個完整單季、普通股可分配損益、加權平均股數、統一拆配股基準與來源都須明示。程式驗證算式；財報內容由使用者核對，保留人工來源標示。
- 台股 TTM 需為連續12個月、以季末結束；只有同一明確12個月的報告值可直接使用，不把年度EPS滾成今天的TTM，不加總不同基準的季度EPS。
- ROE 保留淨利、期初／期末權益及計算範圍，畫面可查看；官方年度ROE與FinMind計算ROE保留各自的來源。
- 新增手動官方來源驗證工作 **Verify Taiwan annual EPS and ROE source**，最多四次唯讀請求，不修改資料或發LINE。

- 公開行情快取到期後，會在既有限額內嘗試更新；來源失敗或額度用完時保留舊資料，顯示原因及原本時間。
- 必要條件缺資料，或行情過舊／不完整時，不取得「買／強力買」；已有資料的分數仍會保留，並另外顯示完整度。
- 網站先取得行情，再安排背景基本面批次；每 4 秒查看狀態，批次結束後刷新結果並提醒。
- 網站、LINE、個人追蹤、掃描及通知共用多因子計算。近一年簡易檢核另行標示，不代表個人多因子分級。
- 上市個股加入證交所公司資料 PDF 的完整年度 EPS 來源；驗證股票代號、產製日期、表頭及年度欄位，遇格式不符保留舊值。
- 官方 Q4 年度 EPS 快照會累積保存，新的季度快照不會把先前年度紀錄擠掉；個人補登仍優先於共用資料。
- 新增每天四次的獨立續補排程，不必等盤後掃描，也不會藉此發送 LINE 訊息或加入個人追蹤。
- 資料庫工作鎖防止不同程序同時修改年度下載狀態；來源請求使用共用每日計數器。
- 新增逐欄缺漏原因、管理者狀態頁、資料庫就緒檢查及過期暫存紀錄清理。
- 個股及 ETF 的近 365 天配息率會從發放事件重新計算；不重用過期的百分比，也不因重建財報而把舊配息來源當成新資料。

## 必要設定

Render 與 GitHub Actions 必須指向同一個 PostgreSQL `DATABASE_URL`。

| 設定 | 放置位置 | 用途 |
| --- | --- | --- |
| `DATABASE_URL` | Render Environment + GitHub Secrets | 共用持久資料庫 |
| `FINMIND_TOKEN` | Render Environment + GitHub Secrets | 台股財報／股利與指定美股日線；GitHub Secret 不會自動傳入 Render |
| `SEC_USER_AGENT` | Render Environment + GitHub Secrets | 使用 SEC 美股財報時設定，須包含維護者 Email |
| `API_BASE_URL` | Streamlit Secrets | 指向既有 Render API，勿指向 localhost |
| `ADMIN_LINE_USER_IDS` | Render Environment，選用 | 允許查看系統狀態的 LINE userId，多人以逗號分隔；未設定時無人有管理權限 |
| 既有 LINE Login／Messaging 設定 | 沿用現有環境設定 | 保持原本登入、簽名驗證及通知功能 |

新增的官方年度 EPS／ROE 及原上市 EPS PDF 都不需要 FinMind token；FinMind 財報、股利及指定美股日線仍需對應來源設定。

## 資料來源的實際範圍

| 欄位 | 自動來源／限制 |
| --- | --- |
| 上市年度 EPS | MOPS 財務比較 E 點通第4季累計／全年來源；原 TWSE PDF 與 Q4 快照保留為補充 |
| 上櫃年度 EPS | 新增 MOPS 財務比較 E 點通全年歷史來源；只有來源實際涵蓋的年度才填入 |
| TTM EPS | 明確12個月報告值，或使用者核對獲利與同基準加權股數的計算；沒有可信資料仍留白 |
| 年度 ROE | 新增官方全年財務分析來源，另保留 FinMind 全年淨利／平均權益計算及依據 |
| TTM ROE | 四個連續單季合併總淨利／期初期末合併總權益平均；保留期間、原值與範圍，缺值不計算 |
| 台股近 365 天已發配息率 | 來源有完整發放日期、幣別與可用股價時重算；已知拆股／配股風險時保守留白 |
| 美股已發配息日期 | 目前專用發放日期來源仍只有 AAPL；其他美股明示尚未支援 |
| ETF 年度總費用率 | 尚未接入完整自動核對來源；不以管理費或 Yahoo 未核對欄位冒充 |
| 美股多年年度現金殖利率 | 仍可能缺逐年已發配息／年底價格，不以宣告股利替代 |

加入待補清單不保證來源一定涵蓋所有指標；資料集數不等於欄位完整度。「本批完成」只表示這一批處理已結束。

## 更新頻率與上限

- 網站背景批次：最多兩次外部來源請求；各資料步驟採軟預算；官方資料與年度財報步驟各最多12秒，PDF改為連線8秒／讀取12秒、串流經過30秒時停止，另計解析時間。第一次可能先完成目錄及公司識別快取，再由排程續補數值。
- 查詢下載共用每分鐘 2 批、每日 30 批；同標的 5 分鐘內不重複安排。
- 公開行情更新沿用每分鐘 2 次、每日 20 次限制；有舊資料時限額用完仍顯示舊資料與原因。
- 本系統年度／美股日線下載共用 FinMind 每日 100 次、SEC 每日 60 次；TWSE EPS PDF 每日 12 次、新增官方年度財務來源每日48次。這是本系統上限，不代表供應商帳號的實際可用額度。
- 獨立續補排程：台灣時間 03:41、09:41、15:41、21:41。GitHub 排程可能延遲。
- 每次獨立續補另加入最多4次官方年度財務請求，並保留最多 2 個官方基本面端點、2 份 EPS PDF、8 次年度來源請求、2 檔指定美股日線及 1 份已支援配息頁；沒有待處理工作就略過。
- 查詢需求最多保留 100 檔、14 天；官方／年度來源快取與冷卻繼續限制重試頻率。
- 下載時間為軟預算；資料庫、連線及 PDF 解析可能延長實際時間。前景不等待基本面下載，頁面關閉或服務重啟後，由後續排程恢復續補。
