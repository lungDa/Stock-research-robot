5. 先以歷史資料做回測與模擬交易，並分離實際委託。

## 軌道二：元大 API 開通準備
取得正式核准通知後，逐項確認：
- 行情 API、交易 API 是否分別授權；台股上市／上櫃與 ETF 的涵蓋範圍。
- 官方 SDK／文件版本、支援的作業系統與 Python 版本。
- 逐筆／快照／分鐘 K 棒可用性、歷史回補與頻率限制。
- 認證方式、IP 白名單、連線時段、斷線重連、行情時區與時間戳。
- 免費／付費行情條款、資料保存及轉發限制。
- Render 雲端部署是否符合 SDK、固定 IP、連線與授權條件。

## 安全要求
- 不要將帳號、密碼、API 金鑰、憑證或私鑰提交到 GitHub。
- 憑證僅在確認 SDK 後透過安全的部署環境變數／祕密管理配置。
- 交易權限即使核准，也不會自動啟用實盤下單。
- `app/day_trader/yuanta_readiness.py` 只做開通條件檢核，並非真實 API 連線。

## 上線驗收
確認授權 → SDK 沙盒或只讀連線 → 時戳與延遲驗證 → 限流／斷線測試 → 歷史回測 → 人工審查。實盤委託須另外明確授權。
