## 累積修改範圍

- 推薦依原始條件優先補足名額，保留每檔實際放寬輪次及現金流硬性條件。
- 推薦 Flex 卡片與持久化傳送佇列；六項資料初步缺漏診斷與輪替續補。
- 各來源以獨立程序更新，保存進度、冷卻、時間與請求限制的中文診斷。
- 年度 EPS／ROE 身分檢查、安全失敗分類與資料庫強制唯讀的冷卻查詢。

## 審核發現與修正

1. 推薦連結帶入的股票代號未被網頁讀取：加入單次帶入與格式檢查，切換股票時清除舊顯示；使用者按「分析」才發出查詢。
2. 年度與現金股利工作的鎖原先分別為 60／75 秒，短於父程序 65／90 秒的上限：延長至 180 秒，降低程序尚未停止卻被其他工作接手的風險。
3. 現金股利游標固定跳兩年：改依實際走訪年數前進，避免單次一請求、偶數年度範圍漏查部分年份。

新增回歸測試涵蓋推薦連結到選取股票、無效參數、使用者改選保留、單請求跨年度輪替及鎖期限。
完整 HTTP、LINE、財報與其他既有測試由 GitHub CI 驗證；測試使用模擬來源，不發送正式 LINE 訊息。
