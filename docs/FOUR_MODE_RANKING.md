# 四模式股票研究排名（研究核心）

本階段提供獨立、可測試的純函式 `app/day_trader/ranking.py::rank_four_modes`：
- 綜合前10：基本面 50%／技術面 50%
- 長期前10：基本面 85%／技術面 15%
- 波段前10：基本面 40%／技術面 60%
- 當沖前10：基本面 10%／技術面 90%

以上為**暫定初始權重**，並非 AI 學習出的最適權重；資料完整度不足時不會偽造分數。
若只有一類完整資料，長期／波段／當沖會以該模式主要分數排名，
並明確保留另一類分數缺漏；綜合榜要求兩類都完整。
`data_stale=True` 的個股全部排除。

**尚未接入**全市場資料蒐集、現有多因子評分、分鐘K棒技術分數、
Streamlit 頁面、LINE 推播、模型推論或實盤／模擬自動委託。
正式接入前，需先定義資料時效與技術分數換算標準，並完成歷史回測。
所有結果均為研究用（`tradable=false`）。
