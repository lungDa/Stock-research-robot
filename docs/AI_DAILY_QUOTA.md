# AI 每日智慧額度：40 檔股票分析

- 使用者選擇每日 **40 次完整股票 AI 分析**，11:30 與 19:30 共用同一額度，不是每次各40次。
- Gemini 主用、OpenAI 備援；一次股票分析可發生多個供應商 API 請求，因此 **40次分析不等於40次計費請求**。
- 排序原則：首次進入前十、最佳排名較高、評分變化較大；同股票候選去重。
- 額度不足時，保留量化結果，AI 分析延後，不偽造分析結果。
- `ai_quota.prioritise` 是候選排序與規劃，**尚未**接入持久化原子額度扣減、每日台灣時區重置、Gemini/OpenAI API 批次調用、Streamlit／LINE排程。
- 正式上線前需建立跨程序的原子扣額、失敗重試規則、每日成本上限、執行紀錄及預算警示。
