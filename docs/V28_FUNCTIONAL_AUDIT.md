# 2.8 功能完善與驗收

## 本次可直接修正的缺口

- 模擬交易：統一上市代號簡寫，避免拆分持倉與繞過上限；交易中以帳戶鎖合併舊別名持倉，失敗時整筆回滾。上櫃 `.TWO` 保持獨立。
- 新增 `paper_order_details` 附屬表，保存商品類別、交易方式、原成交稅費；既有表不修改欄位。舊委託缺少的費用標示未記錄，不猜測或補算。
- 模擬帳戶顯示風險上限及最近30筆成交；預設零股模式與100股一致。
- AI：未設定、認證、限流、逾時、網路、上游與內容異常分類；只輸出固定分類與中文指引，不輸出例外文字、回應本文、網址或金鑰。
- 四模式報表：新增明確的產生操作，讀取最多30檔個人台股追蹤清單的既有快取，不呼叫行情來源或 AI；依個人條件權重與完整性排序，標明非全市場、非買入建議。
- 四榜訂閱獨立於原排名訂閱；排程可產生報告並沿用既有 outbox 防重送。不為空榜推播。
- 分鐘行情未接入時，波段與當沖不得使用日線分數冒充完整資料。保留空榜與原因。
- 網站短暫斷線不再清除有效登入；服務狀態未知與維護訊息分開，提供重試按鈕。正式401仍清除失效登入。
- 前後端共用版本標記；管理員能查閱 AI、LINE、登入與排名的設定條件，所有「已設定」皆不當成已實測。

## 驗證邊界

- 本機測試與 CI 使用隔離資料庫，不向 LINE 發送訊息、不花費 AI 額度、不下真實委託。
- 正式網站首頁已能開啟；個人流程仍需使用者在自己的瀏覽器登入驗收，不能以首頁可開啟代表登入與 OTP 均正常。
- 財報資料齊全程度由官方來源、公告期間、來源額度與冷卻狀態決定。既有診斷、補件與資料覆蓋功能保留，不解除冷卻、不填造缺值。
- 分鐘行情／真實券商不在這次範圍；如要啟用，需另行確認資料服務及授權。
- 部署後需核對 Render 成功、`/ready`、`/version` 與 Streamlit 畫面版本。LINE 實際回覆、AI 供應商連線及帳戶 OTP 不得只以單元測試宣稱驗收完成。
