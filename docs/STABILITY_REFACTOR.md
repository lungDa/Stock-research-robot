# 股海燈塔重構階段紀錄

## 已完成

- PostgreSQL 連線池啟用閒置連線優先回收，最多五條連線。連線建立與等待池中連線各設五秒，保留借出前的連線檢查。既有連線與交易失敗後仍由呼叫端決定是否可重試。
- 快取文件改用原子 upsert。台股備援行情與成功狀態使用同一交易發布。台股月份快取每檔以一條 SQL 讀取四個月。
- Streamlit 定期探測流程改為驗證 Render 的資料庫就緒狀態。健康探測保留原有頻率。
- 移除七份位於儲存庫根目錄的工作流程副本。各副本在修改前與 `.github/workflows/` 內的對應檔案完全相同。
- 加入逆勢研究計算函式，提供五個基準權重、風險分級、可用時間對齊與下行統計。基礎回測依輸入訊號在下一個交易時段進場，支援 10、20、30 個交易日持有期間。這些函式目前只接受呼叫端提供的歷史資料與訊號。

- 市場資料串流會檢查陣列分隔符號及結尾，避免將格式錯誤的行情認定為完整市場資料。
- 台股快取內容無變動時省略寫入。現有個人規則排名每批讀取最多七檔的資料，原為五檔。
- 逆勢核心新增五個基準與綜合排名。排名只放寬零檔符合的門檻，最多輸出十檔。上游仍須提供可比較的基準分數與可用性判斷。

- 排名排程超出發送窗口時回報跳過，提前結束而不讀取資料庫或發送訊息。
- 基本面來源遇到連線、讀取逾時或伺服器錯誤，保留上次成功的資料與狀態，將該來源的下一次嘗試從一天後提前至一小時後。

延遲來自本機 SQLite 記憶體資料庫，每個版本各執行 1,000 次讀取。從開發環境向正式 Render 發送的兩次探測各逾時 12 秒，未取得 HTTP 回應，無法據此判斷正式服務狀態。正式服務延遲、99% 資料完整率、全市場掃描速度、排名速度及全天可用性仍待實測。

## 正式資料覆蓋率抽樣

2026-11-24 台灣時間的既有正式回補排程，針對 80 檔個股、2021–2025 年的 EPS、ROE 及現金股利支出抽查 1,200 欄位，取得 219 欄位，抽樣覆蓋率 18.25%。當時稽核母體為 2,031 檔。這個結果的分母僅為該批與三個欄位，無法用來估計全市場、其他財務指標或行情的完整率。抽樣也記錄到 TPEx 讀取逾時。

## 後續驗收

- 現有月線回補只排四個月。逆勢功能需要可驗證的 1、3、5 年台股還原歷史、五個基準的歷史價格、台美交易日曆與時點財報。
- 完成資料取得後，還需接入市場排名、調參與個人開關、60 分鐘監控、LINE 去重通知和進出場訊號。
- 回測核心尚無歷史訊號產生流程或平台入口。交易稅、手續費、滑價與流動性未計入。

## 部署與回滾

經審查批准後，先在測試環境確認 `/health`、`/ready`、網頁載入及台股備援行情寫入，再進行正式部署。使用既有資料表，無須結構遷移。若部署後出現回歸，重新部署上一版程式，並透過回滾 PR 撤回本階段提交。快取文件沿用原有格式。

## 台股還原歷史試跑

在具有既有 FinMind 授權的測試環境執行 `python -m jobs.refresh_defensive_history 2330.TW 2317.TW`。每次最多處理兩檔，沿用 FinMind 共用額度和冷卻狀態。若缺歷史日曆，每次先補一個年度，待所需年份齊備後才下載還原日線。資料按代號存入 `defensive:adjusted:` 命名空間，既有報價快取格式無須遷移。

涵蓋率以各區間的交易所開市日為分母。新上市、暫停交易及資料源缺漏都可能使涵蓋率下降，目前尚未按個股掛牌與停復牌日期調整分母。下行統計用的日報酬可由還原收盤價產生，遇到缺漏交易日便保留缺值。工作尚未接入正式排程。

## 美國指數歷史

`python -m jobs.refresh_defensive_indices` 從 FRED 下載 Nasdaq-100（NASDAQ100）與費城半導體（NASDAQSOX）的近五年日收盤值。每次最多兩次有時間與大小上限的請求。同一小時重複執行會使用快取，來源失敗或最新觀測日倒退時保留已存資料。

FRED CSV 的日期是觀測日，缺少逐筆可取得時間。研究函式 `align_us_index_history` 需要已核對的美國交易日收盤時刻及逐筆公布時間，才能分配到其後第一個台灣開盤。跨美國缺失交易日或缺公布時間的報酬保留缺值。還未接入歷史公布時間資料源，因此 FRED 收盤資料本身不能啟用歷史訊號。台灣電子類及半導體類指數也尚未接入。

- [FRED NASDAQ100](https://fred.stlouisfed.org/series/NASDAQ100)
- [FRED NASDAQSOX](https://fred.stlouisfed.org/series/NASDAQSOX)

## 台灣類股指數歷史

`python -m jobs.refresh_defensive_tw_indices` 使用證交所 MI_INDEX 的 `IND` 報表。每一交易日同時核對電子工業類及半導體類的價格指數，兩者齊全才寫入。每次最多抓兩個交易日，由近期往回補，已有日期直接重用，失敗交易日冷卻一小時。工作會回報五年多七天的交易日數與已取得日數。此工作尚未排程，完整回補需要多次執行。

快取包含抓取時刻，這個時間只代表本系統實際讀到資料的時間。歷史報表未附原始公布時刻，因此仍需可靠的時點資料才能驗收歷史訊號。

## 個股逆勢統計報告

已準備日曆及個股快取後，可執行 `python -m jobs.report_defensive_research 2317.TW` 取得 JSON。此工作只讀取資料庫。各基準按 1／3／5 年回報可配對交易日數、覆蓋率及下行統計。預設需要 60 組配對，且大跌門檻為 2%，可由命令列調整。

台灣基準使用同一交易日收盤，只供歷史描述統計。美國基準需要逐日收盤時刻及可取得時間。缺少資料或自行比較台積電時會回傳各自的狀態。已登入的使用者也可透過 `GET /defensive/research/{symbol}` 查詢，可傳 `min_pairs` 和 `severe_drop`。此報告尚未接上全市場排名、Streamlit 或推播。
