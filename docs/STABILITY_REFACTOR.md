# 股海燈塔重構階段紀錄

## 已完成

- PostgreSQL 連線池啟用閒置連線優先回收，最多五條連線。連線建立與等待池中連線各設五秒，保留借出前的連線檢查。既有連線與交易失敗後仍由呼叫端決定是否可重試。
- 快取文件改用原子 upsert。台股備援行情與成功狀態使用同一交易發布。台股月份快取每檔以一條 SQL 讀取四個月。
- Streamlit 定期探測流程改為驗證 Render 的資料庫就緒狀態。健康探測保留原有頻率。
- 移除七份位於儲存庫根目錄的工作流程副本。各副本在修改前與 `.github/workflows/` 內的對應檔案完全相同。
- 加入逆勢研究計算函式，提供五個基準權重、風險分級、可用時間對齊與下行統計。基礎回測依輸入訊號在下一個交易時段進場，支援 10、20、30 個交易日持有期間。這些函式目前只接受呼叫端提供的歷史資料與訊號。

- 市場資料串流會檢查陣列分隔符號及結尾，避免將格式錯誤的行情認定為完整市場資料。
- 台股快取內容無變動時省略寫入。現有個人規則排名每批讀取最多七檔的資料，原為五檔。
- 逆勢核心新增五個基準與綜合排名。排名只放寬零檔符合的門檻，最多輸出十檔。上游仍須提供可比較的基準分數與可用性判斷。

- 排名排程超出發送窗口時回報跳過，提前結束而不讀取資料庫或發送訊息。
- 基本面來源遇到連線、讀取逾時或伺服器錯誤，保留上次成功的資料與狀態，將該來源的下一次嘗試從一天後提前至一小時後。

## 正式資料覆蓋率抽樣

2026-11-24 台灣時間的既有正式回補排程，針對 80 檔個股、2021–2025 年的 EPS、ROE 及現金股利支出抽查 1,200 欄位，取得 219 欄位，抽樣覆蓋率 18.25%。當時稽核母體為 2,031 檔。這個結果的分母僅為該批與三個欄位，無法用來估計全市場、其他財務指標或行情的完整率。抽樣也記錄到 TPEx 讀取逾時。

## 後續驗收

- 現有月線回補只排四個月。逆勢功能需要可驗證的 1、3、5 年台股還原歷史、五個基準的歷史價格、台美交易日曆與時點財報。
- 完成資料取得後，還需接入市場排名、調參與個人開關、60 分鐘監控、LINE 去重通知和進出場訊號。
- 回測核心尚無歷史訊號產生流程或平台入口。交易稅、手續費、滑價與流動性未計入。

## 部署與回滾

經審查批准後，先在測試環境確認 `/health`、`/ready`、網頁載入及台股備援行情寫入，再進行正式部署。使用既有資料表，無須結構遷移。若部署後出現回歸，重新部署上一版程式，並透過回滾 PR 撤回本階段提交。快取文件沿用原有格式。

## 台股還原歷史試跑

在具有既有 FinMind 授權的測試環境執行 `python -m jobs.refresh_defensive_history 2330.TW 2317.TW`。每次最多處理兩檔，沿用 FinMind 共用額度和冷卻狀態。若缺歷史日曆，每次先補一個年度，待所需年份齊備後才下載還原日線。資料按代號存入 `defensive:adjusted:` 命名空間，既有報價快取格式無須遷移。

涵蓋率以各區間的交易所開市日為分母。新上市、暫停交易及資料源缺漏都可能使涵蓋率下降，目前尚未按個股掛牌與停復牌日期調整分母。下行統計用的日報酬可由還原收盤價產生，遇到缺漏交易日便保留缺值。工作尚未接入正式排程。

## 美國指數歷史

`python -m jobs.refresh_defensive_indices` 從 FRED 下載 Nasdaq-100（NASDAQ100）與費城半導體（NASDAQSOX）的近五年日收盤值。每次最多兩次有時間與大小上限的請求。同一小時重複執行會使用快取，來源失敗或最新觀測日倒退時保留已存資料。

FRED CSV 的日期是觀測日，缺少逐筆可取得時間。研究函式 `align_us_index_history` 需要已核對的美國交易日收盤時刻及逐筆公布時間，才能分配到其後第一個台灣開盤。跨美國缺失交易日或缺公布時間的報酬保留缺值。還未接入歷史公布時間資料源，因此 FRED 收盤資料本身不能啟用歷史訊號。台灣電子類及半導體類指數也尚未接入。

- [FRED NASDAQ100](https://fred.stlouisfed.org/series/NASDAQ100)
- [FRED NASDAQSOX](https://fred.stlouisfed.org/series/NASDAQSOX)

## 台灣類股指數歷史

`python -m jobs.refresh_defensive_tw_indices` 使用證交所 MI_INDEX 的 `IND` 報表。每一交易日同時核對電子工業類及半導體類的價格指數，兩者齊全才寫入。每次最多抓兩個交易日，由近期往回補，已有日期直接重用，失敗交易日冷卻一小時。工作會回報五年多七天的交易日數與已取得日數。此工作尚未排程，完整回補需要多次執行。

快取包含抓取時刻，這個時間只代表本系統實際讀到資料的時間。歷史報表未附原始公布時刻，因此仍需可靠的時點資料才能驗收歷史訊號。

## 個股逆勢統計報告

已準備日曆及個股快取後，可執行 `python -m jobs.report_defensive_research 2317.TW` 取得 JSON。此工作只讀取資料庫。各基準按 1／3／5 年回報可配對交易日數、覆蓋率及下行統計。預設需要 60 組配對，且大跌門檻為 2%，可由命令列調整。

台灣基準使用同一交易日收盤，只供歷史描述統計。美國基準需要逐日收盤時刻及可取得時間。缺少資料或自行比較台積電時會回傳各自的狀態。已登入的使用者也可透過 `GET /defensive/research/{symbol}` 查詢，可傳 `min_pairs` 和 `severe_drop`。Streamlit 的「逆勢研究」分頁在登入後提供同一份報告，可切換 1／3／5 年與設定大跌門檻。同一分頁也可讀取全市場排名快照。LINE 推播尚待接入。

## 全市場歷史逆勢命中率

`python -m jobs.rank_defensive_market` 使用最近 48 小時內核對過的上市／上櫃普通股母體。掃描由資料庫分批讀取，將已掃描／總檔數及各期間達最低門檻的檔數回報到標準錯誤。只納入已回補至目標收盤日的個股。已登入使用者可透過 `GET /defensive/market-ranking` 讀取最近一次快照。快照記錄母體與符合當日行情的檔數、各基準可用狀態及近 1／3／5 年排行。

本階段分數採基準下跌日的個股上漲比例，至少需要 60 組配對與 20 個基準下跌日。預設 60%，只有零檔符合才逐級嘗試 55%、50%，各榜最多 10 檔。綜合榜須具備全部五個分數。此為歷史描述排名，LINE 推播尚待接入。缺乏逐日公布時間時，美股基準及綜合榜可能無法計算。

Streamlit 入口在「逆勢研究 → 全市場排名」。按「讀取最新排名」後可以切換期間與基準，切換只重用已讀取的快照。畫面標示收盤日、行情涵蓋檔數、門檻、符合檔數與基準缺漏。

全市場快照另含「基本面與技術篩選」榜。基本面沿用既有預設八項年度規則與共用財報，技術條件要求還原收盤價高於 20 日均線，且 20 日均線高於 60 日均線。缺任一必要項目便排除於篩選榜，放寬逆勢命中率時也維持原篩選條件。此篩選用於當期排名，完整財報公布時點的歷史回測仍待驗證。

## LINE 逆勢通知

Streamlit 的「逆勢研究 → LINE 通知」允許已登入使用者各自開關，預設關閉。通知工作預設只預覽待發事件數，帶 `--send` 才會透過 LINE 官方帳號推送。已驗證且尚在 90 分鐘內的風險快照存於 `defensive:risk`，需有 `verified`、`level`、`observed_at` 欄位，高風險可用 `ranking_as_of` 指定同一收盤日排名。是否啟用收盤風險監控及每小時排程由下方變數控制。

Level 2 初次進入時提醒，Level 3～4 可附近一年五基準篩選榜。風險升級、前三名順序變動或至少兩檔換入換出、回落至 Level 0～1 時推送。無已驗證的新觀測便停止推播。工作重用既有 LINE 配額與重送識別碼。

收盤風險工作 `python -m jobs.monitor_defensive_risk` 在台灣交易日 18:17 後核對五個當期基準報酬，只有五項齊備才發布風險等級。同一交易日重跑會重用快照。可透過資料庫文件 `defensive:risk:configuration` 設定四級的 `single_drop`、`multi_drop`、`declining_count`、`weighted_drop` 及五基準 `weights`，跌幅以小數表示。Streamlit 的 LINE 通知分頁可查看最近一次已驗證的收盤風險。

新增 GitHub Actions 每小時依台灣交易日曆檢查，只有 `DEFENSIVE_RISK_ENABLED=true` 才會執行，LINE 另須 `DEFENSIVE_LINE_SEND=true` 才發送。此流程以已存行情為輸入，盤中報價及美股逐日公布時間來源仍待完成。正式執行前需在測試環境驗證資料及通知。

啟用收盤風險排程後，會先執行 `python -m jobs.refresh_defensive_inputs`，依序更新 FRED 兩個指數、證交所兩個指數及台積電還原日線。沿用各來源的快取、請求上限及 FinMind 共用額度。單一來源失敗會獨立回報，其餘來源與風險核對仍會執行。缺 FinMind 金鑰的環境仍可更新指數資料。基準更新與全市場個股回補分開控制。

選用的 `DEFENSIVE_UNIVERSE_BACKFILL=true` 會在基準更新後輪替回補核對過的上市、上櫃普通股，每次最多兩檔，台積電由基準工作處理。遇到額度或日曆阻擋時，保留首個未處理位置。暫時失敗或冷卻的個股會在下一輪重訪。此旗標預設停用，完成一輪的時間取決於可用額度，尚未驗證能每日回補全市場。

每小時排程在台灣收盤後，會於 LINE 通知前嘗試產出當日排名。已成功產出的當日快照在同一交易日重用，手動跑排名工作仍可重新產出。排程給排名工作 75 秒的預算，遇資料缺漏、失敗或逾時會保留原快照並繼續處理風險通知。LINE 只會附上與風險快照屬同一收盤日的可用篩選榜。

若先送出了高風險提醒，之後同一風險觀測時限內才出現當日篩選榜，LINE 可補送新榜單。完全相同的榜單重跑不會重複發出，風險過期後也不補送。

## 波段訊號與固定持有期回測

收盤監控保留每個交易日的已驗證風險快照，既有當日快照也可補記到歷史。已登入使用者可透過 `GET /defensive/swing/{symbol}` 取得個股的最新波段訊號與 1／3／5 年、10／20／30 日持有期績效；`holding=true` 可查看持倉情境。進場規則為 Level 2～3 且還原收盤價高於 20 日均線，且 20 日均線高於 60 日均線。Level 4 或收盤跌破 20 日均線可提示減碼，收盤跌破 60 日均線提示退場。

回測於訊號後第一個交易日開盤進場，依完整交易日曆計算固定持有期。進出場當日缺還原開盤價便略過該筆，未完成持有期也不列入統計。現階段回測採五基準綜合風險，尚無各基準的實際獨立策略績效，也未模擬減碼和提早退場、交易成本及流動性。過去未保存的風險觀測無法追溯。此功能只提供研究訊號及模擬結果。
